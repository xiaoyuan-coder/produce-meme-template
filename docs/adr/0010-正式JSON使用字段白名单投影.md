# ADR 0010：正式 JSON 使用字段白名单投影

- 状态：已接受；`image.extract` 结论已由 ADR 0022 取代
- 日期：2026-08-16

## 背景

两份最新数据样例包含正式运行字段，也包含旧 Unified 的候选策划、推荐项解释、运行能力和 843 条修订审计。开放 metadata 允许它们通过 Schema，但通过 Schema 不代表生成后端会消费。

## 决定

新 Skill 从完整生产模型编译正式 JSON 时使用白名单投影。默认 metadata 只保留 `tags`；存在人工复核原因时增加 `needsReview`。候选策划、六维分析、推荐项理由、版本能力和审核信息进入 sidecar。

v1 合同中 `inputSchema[].image.extract` 只承担简短语义留档。v2 新生产项已删除该字段，输入目标与视觉合同进入 `runtimeSemantics`。

## 影响

- 正式 JSON 更小，且不再暴露旧流程概念。
- 完整生产证据仍可追溯，不因投影删除。
- 编译器必须同时验证正式投影和 sidecar 完整性。
