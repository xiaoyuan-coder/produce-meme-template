# ADR-0029：所有独立审计结论进入最终关键资格账本

- 状态：Accepted
- 日期：2026-08-27

## Context

部分作者与语义规则已有独立审计，却没有进入 P8 重算的关键资格账本。这使得身份与服装继承、文字路由、默认值简洁性、标题与描述根据等结论可以在中间阶段看似合格，最终交付却无法证明它们仍然完整。

## Decision

P4 在同一次独立作者审计中新增三组逐项证据：

- title/description 对 Approved Image 的根据、口语自然度和槽位可迁移性；
- subject 从上传图继承的身份与服装特征，以及模板固定例外的最小性；
- 每个默认值的用户语言、单一编辑轴和最短自然表述。

P6 继续复用现有独立语义与视觉合同审计，不增加新的模型调用。ADR 0030 加入来源目标画布和来源标记策略后，P8 从已持久证据重算 27 项关键结果，覆盖第一阶段换图、来源画布、标记处置、Approved Image、用户文案、主体策略、高价值槽位、身份继承、默认值、Prompt 代入、用户权限、标题迁移、推荐项、runtimeSemantics、身份文字、可见文字、渲染一致性、画风媒介、标签和正式记录合同。

资格 ID 由 `contracts/machine-rules.json` 唯一定义。P8 精确对账资格账本与当前重算结果；缺失、重复、删改或任一否定都停止 OSS 上传和正式投影。生产谱系、执行画像、资产凭证和 `cover === referenceImage` 继续由原有交付资格门禁独立强制。

## Consequences

- 新门禁只重用已经产生的证据，不增加 Fal、OSS 或大模型调用。
- `authoring-contract-audit.json` 和 `critical-outcome-qualification.json` 的内部合同升级。
- 新的独立审计项需要红绿公共流程测试和历史经验 ID；删除任一资格角色会在仓库合同测试中失败。
