# 稳定版按发布风险分级验收

稳定版候选把 `releaseReadinessProfile` 冻结进 `release.json` 和 `release-lock.json`。首个稳定版、SemVer major 变化以及主动声明外部风险的候选使用 `live_external`，执行安装后未见图前向、四场景 Fal/OSS live 和人工视觉审核。同一 major 内的兼容 minor/patch 可以使用 `compatible_minor`，完成全量构建验证、双轴 clean code review、全新临时安装和 doctor 后晋升，不调用 Fal、OSS 或人工逐图审核。0.x 开发版使用 `development`。

候选构建时从 code-review 比较基线读取上一 `skillVersion`，机器校验声明的 profile 是否足以覆盖版本变化；候选锁同时冻结比较基线提交、基线版本和 profile。兼容 completion 绑定候选 release digest、被审提交、安装 runtime pin、两份 review receipt 和 doctor 结果，并明确记录无需外部执行。该分级降低日常兼容发布成本，同时保留外部供应链、视觉门禁和 major 变化的完整实测边界。
