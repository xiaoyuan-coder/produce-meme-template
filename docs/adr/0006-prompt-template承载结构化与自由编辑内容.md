# ADR 0006：Prompt Template 承载结构化与自由编辑内容

- 状态：已接受
- 日期：2026-08-15

## 背景

旧规则曾把 Prompt Template 收窄为“只表达开放槽位”，导致没有入槽但仍有编辑价值的画面内容从自由编辑模式消失。843 条最终数据修订与当前产品口径均表明，用户会把整段 Prompt Template 当作自己的生图提示词。

## 决定

Prompt Template 是用户可见、可全文编辑的完整自然语言画面描述：

1. 必须包含全部结构化开放槽位。
2. 可以包含未入槽但仍具有编辑价值的画面内容，供自由编辑模式改写。
3. 不承载锁定媒介、构图、防漂移规则和生产过程术语。
4. 最终字面对主体、文字、颜色、配饰、服装、道具和场景拥有用户内容权限；隐藏字段不能恢复已被用户改写的默认内容。
5. 槽位编辑与全文编辑最终编译为同一种 resolved prompt。

## 影响

- 槽位模型与 Prompt Template 之间不再是完全等价关系。
- 编译器需要同时消费结构化编辑内容和自由编辑内容。
- 校验器需要检查所有槽位均被引用，同时允许 Prompt Template 出现非槽位的可编辑叙事内容。
- hidden constraints 冲突审计成为正式门禁。
