# 用四个可恢复大阶段聚合 P0–P8

模板生产继续保留一个公共工作流和一套 P0–P8 领域状态，同时向用户提供四个可显式调用的大阶段：换图执行、API 模板图生成与确认、模板数据编译、OSS 最终化。分段调用与完整调用复用同一个 Production Item、revision、pin、manifest 和依赖图；每个边界通过产物 SHA 重放后恢复。

第一阶段冻结换图计划与 Generation Package，不触发图片生成。第二阶段通过注入的图片生成 API adapter 执行提交和轮询，真实生产使用 Fal 队列；供应商结果经过视觉门禁后才能成为 Approved Template Image。第三阶段编译并验证待 OSS 的数据包。第四阶段上传当前 Approved Template Image、回填 URL 并生成唯一正式 `gallery-template.json`。

这个聚合层增加人工检查点，同时保留单一端到端入口、不可变谱系和完整生产的一次调用方式。T1 继续使用独立生命周期，不成为第五阶段。
