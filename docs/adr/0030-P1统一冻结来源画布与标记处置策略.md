# ADR-0030：P1 统一冻结来源画布与标记处置策略

- 状态：Accepted
- 日期：2026-08-27

## Context

来源网图可能是独立设计、衣服等商品载体上的印花、带黑框或设备界面的截图，也可能包含水印、普通贴纸、装饰图标和商标。旧迁移证据已经区分这些情况，当前生产合同只保留了泛化的“全画布清洁”。P1 因此可能把载体环境带入换图 Prompt，P2 也可能把合法视觉内容误判为污染，造成重复生图。

## Decision

来源分析必须在 P1 产出两份结构化事实：

- `sourceCanvasDecision`：在 `standalone_design`、`print_artwork`、`screen_content` 和 `full_scene` 中选择一种目标画布，并精确列出目标区域、排除区域、必需动作和要保留的设计内部结构；
- `sourceMarkPolicy`：确认已完成来源标记扫描，对每个标记逐项选择 `remove`、`preserve` 或 `synchronize` 并保存依据。

衣服印花路由固定提取并正视化独立设计，排除衣服、模特、衣架和商品摄影环境。截图内容路由固定裁掉黑色截屏框、设备边框和界面控件。普通贴纸、装饰图标和用户未要求删除的商标默认属于来源视觉内容；删除商标只接受显式用户要求、载体环境、身份依赖冲突或权利阻断依据。水印、平台标、账户标、伪签名和无关 Logo 只能删除。

Generation Package 把两份决策编译进唯一冻结 Prompt 和 `firstStageGate`。P2 审核请求原样携带两份决策，并逐项返回目标画布证据和标记动作证据。`fullCanvasClean` 的最终判定由具体污染发现项和 required-remove 证据派生；泛化布尔值不能单独否决已批准保留的贴纸或商标。`watermarkFree=false` 继续直接阻断，同时接受逐项水印证据的交叉验证。

## Consequences

- P1 缺少目标画布或标记扫描结论时，在调用生图 API 前失败。
- P2 仍会阻断未清除的水印、平台标、无关 Logo 和其他 required-remove 项。
- P8 资格账本新增 `source_canvas_normalization` 和 `source_mark_treatment_policy`，关键结果总数为 27。
- 本变更不增加 Fal、OSS 或模型调用；新增工作全部复用 P1 分析与 P2 视觉审核。
