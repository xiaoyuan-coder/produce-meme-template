# Issue tracker

本仓库使用 [xiaoyuan-coder/produce-meme-template](https://github.com/xiaoyuan-coder/produce-meme-template) 的 GitHub Issues。

- 使用 `gh issue view/list/create/edit` 读取和维护规格与实现票据。
- 完整规格以一个父 Issue 发布；实现票据引用父 Issue，并声明 blockers-first 阻塞关系。
- Agent-ready 规格和票据应用 `ready-for-agent`。
- `xiaoyuan-coder/memebuy-image-analyser` 中的旧 Issue 只提供历史迁移依据，不接收本 Skill 的新票据。
- PR 不作为外部需求收件箱。
