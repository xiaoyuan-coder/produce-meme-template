# 第一阶段替换与生图规范

## 1. 适用范围

本规范负责回答两个问题：

1. 网图中的什么内容需要替换。
2. 应该替换成什么，以及如何编译成可批量调用生图 API 的 prompt。

用户或批次提供策略时，Skill 按策略执行并完成合同检查。未提供策略时，Skill 依据本规范自主决定。所有决定都写入 `ReplacementPlan`，禁止把临时判断只留在对话或自然语言日志中。

## 2. 决策优先级

```text
单图显式策略 > 批次显式策略 > Skill 自主策略
```

显式策略分为：

- **指定替换值**：明确某个目标替换成什么。
- **指定分配规则**：明确 IP 池、人群、主题、媒介或组合比例，由 Skill 做单图分配。
- **指定保留项**：明确文字、语言、关系、构图或某个文化锚点保持不变。
- **指定禁止项**：明确不能出现的身份、物种、品牌、风格或表达。

冲突时依次检查：用户最新单图指令、用户最新批次指令、产品硬约束、安全与权利约束、默认替换规范。仍无法消解时阻断该图并记录冲突，不自行选择风险更高的解释。

策略只覆盖其明确声明的范围。指定了替换值但没有声明重复实例、接触边界和去水印时，Skill 继续依据单图默认规范补齐；跨图去重和组合分配只在显式共享批次策略中补齐。`ReplacementPlan` 的每个关键决定都记录 `decisionSource`，支持 `per_image`、`batch` 和 `autonomous` 混合出现。

单图请求通过可选的 `replacementStrategy` 表达当前 Production Item 的显式策略。字段白名单和结构约束读取 `contracts/machine-rules.json`：

- `replacementValue` 与 `replacementCategory` 成对出现。来源分析 adapter 接收规范化后的单图策略，对指定值单独产生 `explicitReplacementEvaluation`；该值无需预先存在自主 `replacementPool`，仍必须通过类别、语义、视觉、权利和安全硬过滤；
- `forbidValues` 排除不允许选择的值，剩余目标继续由自主规则稳定选择；
- `preserve` 追加用户明确冻结的文字、关系、构图或文化锚点；
- `policyId` 与 `policyVersion` 只提供策略追踪，不单独构成执行动作。

策略列表先规范化排序再计算 Production Item 身份摘要。语义相同但列表顺序不同的请求可以幂等复用；同一 Production Item 改变策略内容时按身份冲突阻断。

`preserve` 与主要目标或依赖闭包重叠时，同一内容会被同时要求冻结和重绘。来源分析 adapter 为每个冻结值返回绑定策略原文的 `preserveConflictEvaluations`，其中使用组件 ID 记录与变更集的语义冲突。工作流校验每个 ID 都属于当前 changed set、布尔值与 ID 列表是否一致，以及证据是否覆盖全部策略值，再于生图前阻断冲突；证据不完整或内部矛盾时按外部分析失败停止。

## 3. 自主替换的决策流程

### 3.1 先抽取原图机制

仅抽取重构需要的信息：

- 核心笑点、情绪或传播价值。
- setup、turn、payoff 及因果方向。
- 主体数量、关系、姿态和接触结构。
- 核心非文字物体、容器、穿戴物和背景作用。
- 文字是否承担笑点，以及原始语言。
- 媒介、形态和构图骨架。

### 3.2 分类原目标

目标类别使用版本化枚举：

- 现实公众人物或偶像。
- 普通真人。
- 历史人物。
- 经典艺术作品主体。
- 明确角色/IP。
- 通用人物、动物、物体或食物。
- 承担主要画面职责的文字内容。
- 场景、背景或非文字视觉属性。
- 未知。

`unknown` 不能进入自动分配。该状态需要补充识别或人工复核。

### 3.3 决定替换对象

默认优先级：

1. 明确的主主体。
2. 承担笑点的核心非文字物体。
3. 能形成明显新鲜感的非文字视觉属性或场景。

原图文字默认冻结。只有显式策略授权，或笑点公式要求等价重写时，文字才进入替换集合。重写必须保持语义角色、时序和语言策略。

来源分析通过 `targetEligibility.textRewriteRequiredByMechanism` 记录笑点机制是否要求等价重写。缺少显式文字替换值且该证据不为 `true` 时，文字路由阻断。

### 3.4 生成替换值候选

候选值依次经过四道硬过滤：

1. **语义连续性**：物种/类别、年龄、性别、数量、关系、角色家族与笑点角色兼容。
2. **视觉兼容性**：姿态、轮廓、接触、穿戴、容器、视角和占位面积可实现。
3. **权利与安全**：来源可用于重构；现实身份、角色 IP、品牌和艺术作品按风险等级处理。
4. **显式共享约束**：仅当用户提供共享批次策略时，检查主题、比例、去重、IP 多样性和组合分配要求。

过滤后再做多样性分配，顺序不能颠倒。多样性不能牺牲笑点和画面关系。

权利或安全证据为 `review` 表示尚无法可靠判定。如果显式指定值仍为 `review`，或自主路由只剩该类候选，返回 `needs_input / NEEDS_REVIEW`；只有确定不兼容、被禁止或风险不通过时才使用阻断结果。

### 3.5 自主策略的类别规则

- 普通真人：由图片模型生成同年龄阶段、性别呈现、人数、关系和角色功能的新真人身份，并对完整人物及关联区域统一重绘。身份资产只在真人感、多人一致性或特定身份稳定性确有收益时作为可选辅助。
- 现实公众人物和偶像：替换为同类别、可准确命名的公众人物或爱豆；保持人物类型、组合结构、粉丝语境和媒介兼容，同步姓名、团名、应援文字、识别色和身份徽标。
- 历史人物和经典艺术主体：只有该身份是文化机制的必要锚点时才能保留语义身份，画面仍需整体重绘并进入权利复核。
- 明确角色/IP：允许自主选择同类别知名 IP，优先匹配角色家族、叙事功能、受众语境、姿态可供性和构图；同一 IP 家族内有可靠角色时可以优先选择家族内替换。身份本身承担不可替代的核心笑点时记录为保留例外。
- 通用动物、物体、食物：选择能维持姿态、关系和笑点的高辨识度新值。
- 文字：保持文字功能和语义类型。身份绑定文字随新身份更新、删除或中性化；普通装饰文字默认保持或锁定。
- 场景或视觉属性：只有主体缺少有效替换价值，且改变该属性能形成稳定模板价值时使用。
- 未知：阻断自动生成。

自主场景路由把上述两个前置条件分别记录为 `targetEligibility.primarySubjectHasReplacementValue=false` 和 `targetEligibility.sceneChangeCreatesStableTemplateValue=true`；任一条缺失或不成立都在生图前阻断。单图策略明确指定场景替换值时，按策略优先级跳过该自主价值判断，指定值仍需通过完整硬过滤。

这里的“资产”指额外提供给模型的身份参考图。它是可选生成辅助，不是自主替换值的唯一来源。`prompt_only` 可以直接生成新的普通真人或可准确描述的同类主体。执行时必须完成完整身份替换和整图媒介统一，局部贴脸、旧身体残留或多人串脸均判失败。

### 3.6 显式共享策略下的跨图分配

本节默认不启用。用户明确提供跨图去重、身份多样性、IP 池、组合比例或专题锚点覆盖策略时，受该策略约束的生产项使用稳定分配：

```text
seed = batchId + templateKey + sourceIdentity
```

- 候选池未耗尽时，活动替换值保持唯一。
- 候选池耗尽后，按最低使用次数进行平衡复用。
- 批次策略可以设定角色家族、IP 池、性别、物种、主题和组合比例。
- 单图 rerun 在输入、规则版本、共享策略和 seed 不变时得到同一分配。
- 每次分配保存池版本、候选列表、过滤原因和最终选择，保证可解释。

没有显式共享策略时，每张图独立选择替换值，不读取其他生产项的身份、候选池使用次数、标题或版本 pin。

## 4. 依赖闭包

替换对象不能只按一个局部框处理。`changedSet` 必须包含目标及所有身份或结构依赖：

- 主体本体、脸、身体、服装和身份标记。
- 同一主体的重复实例、分格、剪影和局部特写。
- 派生颜色、纹理、图案和装备。
- 镜像、倒影、影子、屏幕内容和海报内嵌图。
- 与目标相接的手、爪、衣领、帽子、容器边缘和遮挡边界。
- 因替换而失效的文字标签、名字或身份符号。

`dependencyClosure` 必须是包含非空 `type` 和 `value` 的对象列表。结构损坏表示外部分析证据无效，返回稳定 `externalFailure`；列表为空表示替换范围尚无法可靠判定，返回 `needs_input / NEEDS_REVIEW`。

身份替换时，姓名、英文名、团名、称谓、号码、识别色和身份徽标进入同一依赖闭包。自主模式优先在模板图中删除或中性化这些身份文字；批次策略明确要求保留具体身份表达时，文字必须与新身份一致。后续开放主体槽时，如果确认模板图仍含具体身份文字，模板退回本阶段生成中性版本。

`frozenSet` 包含未获授权改变的内容：

- 构图、镜头、版式和主体数量。
- 笑点机制、关系、动作和因果方向。
- 默认保留的文字、语言和符号拓扑。
- 与替换无关的背景、道具和视觉锚点。
- 原媒介与表现形态，除非策略明确要求改造。

## 5. 生图 prompt 的固定结构

Generation prompt 由下列段落编译：

1. **任务声明**：基于参考图完成整图重构，输出一张可独立使用的新模板图。
2. **替换目标**：明确旧目标的画面位置、实例范围和新目标内容。
3. **依赖闭包**：列出必须同步改变的重复实例、派生内容和接触边界。
4. **冻结项**：列出需要保持的构图、关系、动作、文字、语言和视觉机制。
5. **媒介合同**：媒介、形态、边缘、色彩明暗、表面和构图要求。
6. **残留清除**：旧身份特征、旧颜色、旧轮廓、旧水印、签名、平台标和账户标必须清除。
7. **空间关系**：穿戴、手持、遮挡、压合、前后层级、容器内部和接触点。
8. **输出要求**：尺寸、比例、完整画布、清晰度和禁止额外文字。

prompt 中的“改什么”和“保留什么”都必须来自 `ReplacementPlan`。生成器不能自行扩展替换范围。

网图像素只用于分析和参考。禁止局部复制、裁切粘贴或保留来源水印；即使替换区域较小，也要通过整图生成得到新的模板图。

## 6. 媒介与画面验收

每张生成图使用六维视觉合同验收：

| 维度 | 检查重点 |
| --- | --- |
| medium | 摄影、插画、拼贴、像素、手绘等媒介是否一致 |
| form | 体积、轮廓、比例、脸部数量和主体结构是否成立 |
| edge | 线条、轮廓、软硬边和抠图边缘是否统一 |
| colorAndShading | 色相、明度、光影、平涂或体积光是否匹配 |
| surface | 材质、纹理、噪点、纸张、屏幕或布料表现是否匹配 |
| composition | 版式、镜头、主体占比、留白和视觉顺序是否保持 |

还需检查：

- 主体具有“一眼可辨”的替换差异。
- 物种使用正向识别锚点，并排除容易混淆的反向特征。
- 表情符号、图标和文字按拓扑结构检查，不能只检查字符大意。
- 穿戴和持握包含覆盖、压住、遮挡、前后层级等接触证据。
- 摄影模板没有混入插画式重绘，插画模板没有混入摄影皮肤或镜头特征；混合媒介需要按区域声明。
- 全画布三轮扫描水印：显眼标记、半透明角标、嵌入屏幕或衣物的残留。

## 8. 阻断条件

以下任一情况禁止自主进入生图：

- 目标类别为 unknown。
- 显式策略之间存在无法消解的冲突。
- 找不到同时满足语义和视觉兼容性的替换值。
- 文字承担核心笑点，但是否允许重写无法判断。
- 文化身份或 IP 是核心锚点，权利处理方式未确定。
- 替换依赖闭包无法确定，可能产生半替换结果。
- 原图机制依赖真实人物伤害、敏感身份或其他高风险表达。
